# Data assets — Anuradhapura dashboard

## Committed files (`public/data/`)

| File | Description |
|------|-------------|
| `district.geojson` | District boundary (pcode `LK71`) |
| `ds.geojson` | Divisional Secretariat (DS) boundaries (22 divisions) |
| `gn.geojson` | Grama Niladhari (GN) boundaries (694 divisions) |
| `roads.geojson` | Road linework for map overlay |
| `pois.geojson` | Points of interest for map overlay |
| `stats.json` | Census-driven metrics for district, each DS, and each GN (2024) |
| `manifest.json` | Build summary: feature counts, population, building assignment stats |

`stats.json` powers the seven KPI cards in [src/components/StatGrid.tsx](../src/components/StatGrid.tsx): name, pcode, land area (km²), population, population density, housing units, housing density.

## Regenerating data

Script: [scripts/prepare_overview_data.py](../scripts/prepare_overview_data.py)

- **Input directory (default):** `../datasets` relative to repo root (sibling folder `datasets` under `Studio 4 - Level 2`)
- **Override:** set environment variable `DATASETS_DIR` to the folder containing source layers and census tables
- **Output:** writes GeoJSON and `stats.json` / `manifest.json` under `public/data/`; building shards under `public/data/buildings/`

Do **not** commit the full `datasets/` tree or `settlement_change_anuradhapura/` analysis folders into this dashboard repository. Reference them only on your machine or in separate storage.

## External analysis

Road, settlement, and land-cover analysis for Anuradhapura may live in local GIS project folders (for example `settlement_change_anuradhapura/`). Only **processed** outputs required by the web app belong in `public/data/` here.
